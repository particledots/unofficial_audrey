Unofficial Audrey - third-party licences
========================================

Unofficial Audrey is a community plugin. It is not a Synthux Academy product.
Please do not contact Synthux Academy about problems with it.

It is a plugin port of the open-source Audrey feedback-synth engine
(AudreyTouch / Audrey-II firmware). Source: https://github.com/particledots/unofficial_audrey


1. Audrey engine (src/engine)
-----------------------------
Original engine by Nick Donaldson (Infrasonic Audio). Simple Touch port by
Alberto Berera and Rosa Schuurmans. USB MIDI by Vlad Litvinenko.
Audrey-II changes by Synthux Academy. Modified here for use in a plugin
(see PORTING-NOTES.md in the source). The envelope in env.h is derived from
Stages by Emilie Gillet (MIT).

3. DaisySP-LGPL (third_party/daisysp-lgpl) - LGPL-2.1
------------------------------------------------------
DaisySP-LGPL (the ReverbSc reverb and the Tone one-pole filter)
Copyright (c) 2023 Electrosmith, Corp., Sean Costello, Istvan Varga, Paul Batchelor
Published under the GNU Lesser General Public License, version 2.1.
Full licence text: third_party/daisysp-lgpl/LICENSE in the source repository.

The plugin links these two files (reverbsc.cpp, tone.cpp) statically. reverbsc.h
was modified: DSY_REVERBSC_MAX_SIZE was multiplied by 4 so sample rates up to
192 kHz fit (the change is marked in the file). You may modify the library and
relink: the complete corresponding source, including the build files, is in the
repository above, and GitHub Actions rebuilds the plugin from it.
